# Project

This directory defines the high-level concepts, business logic and architecture of the project in markdown, managed with the `tg` CLI (compatible with lat.md). Run `tg check` to validate it.

- [[code-ontology]] — shared vocabulary of intent types and typed edges between intent and code
- [[capabilities]] — the nine capabilities, one per OpenSpec spec
- [[architecture]] — the layers of typedb-lean and the capability each realises
- [[decisions]] — design choices with their alternatives and reasons
- [[constraints]] — external facts about the driver, server and toolchain that bind the design
